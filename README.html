Patreon Creator Skill

Un MCP server completo per creator Patreon: analisi supporter, intelligence competitiva, generazione contenuti, pubblicazione automatica e gestione commenti con RAG. Funziona con qualsiasi agente MCP — Hermes, OpenClaw, Claude, GPT, Llama, Mistral.

ℹ️
Design Model-Agnostic: lo skill non chiama nessun LLM direttamente. I tool restituiscono dati strutturati + un campo *_prompt che il tuo agente passa al suo modello. Compatibile con Hermes, OpenClaw, Claude, GPT, Llama, Mistral — qualsiasi agente MCP.

⚡ Quick Start

Dall'installazione al primo tool in meno di 5 minuti.

1

Ottieni il Creator Access Token

Vai su patreon.com/portal → crea un client → copia il Creator Access Token

2

Installa lo skill (installer autonomo)

Terminalbash
curl -sSL https://raw.githubusercontent.com/nuspy/patreonskills/main/install.py \
  | python - --token pat_TuoTokenQui --client claude
3

Riavvia il tuo MCP client

Riavvia Claude Desktop / Cursor / VS Code per caricare il nuovo server MCP.

4

Verifica la connessione

💬 Dì al tuo agente
"Controlla la connessione Patreon e dimmi qual è il mio campaign ID"

L'agente chiamerà patreon_check_connection e poi campaign_get_overview

5

Indicizza la tua knowledge base

💬 Dì al tuo agente
"Indicizza tutti i miei post Patreon nel knowledge base usando il campaign ID [ID]"

📦 Installazione

Metodo 1: Installer automatico (raccomandato)

Installer autonomo — un solo comandobash
# Installa e configura per Claude Desktop
python install.py --token pat_TuoToken --client claude

# Per Cursor
python install.py --token pat_TuoToken --client cursor

# Con venv + Playwright + LLM locale
python install.py --token pat_TuoToken --client claude \
  --venv --playwright \
  --llm-url http://localhost:11434 --llm-model hermes3

# Per CI/CD con output JSON per l'agente
python install.py --token-file /run/secrets/patreon_token \
  --client claude --quiet --output-json /tmp/result.json

Metodo 2: Installazione manuale

Terminalbash
git clone https://github.com/nuspy/patreonskills
cd patreonskills
pip install -r scripts/requirements.txt
playwright install chromium  # opzionale
export PATREON_ACCESS_TOKEN=pat_TuoTokenQui
python scripts/auth.py status

🧠 Knowledge Base (RAG)

Storage locale ChromaDB con embedding all-MiniLM-L6-v2. Nessuna API key. Dati in ~/.patreon/knowledge_base/

Indicizza tutti i post in ChromaDB. Esegui una volta, poi periodicamente.

kb_add_document RAG
Aggiunge FAQ, brand voice, info prodotto o documenti custom.

kb_search RAG
Ricerca semantica. Su tutte le collezioni o una specifica.

kb_list_documents RAG
Lista documenti in una collezione con metadati.

🏗️ Architettura

Design Model-Agnostic

Il server MCP non chiama nessun LLM direttamente. Funziona con qualsiasi agente MCP.

Come funzionano i tool AI-Prompt

1. Agente chiama tool→ es: campaign_generate_growth_strategy(campaign_id="123")
2. Tool fetch dati API→ chiama Patreon API, aggrega metriche
3. Tool restituisce→ dati strutturati + strategy_prompt pronto
4. Agente usa il prompt→ passa a Hermes/Claude/GPT/Llama: genera piano di crescita

🔧 Troubleshooting

Errore: "Patreon credentials not found"

python scripts/auth.py status
python scripts/auth.py token pat_xxx
# oppure:
export PATREON_ACCESS_TOKEN=pat_xxx

Errore: "Browser automation not configured"

# Aggiungi al .env:
PATREON_EMAIL=tua@email.com
PATREON_PASSWORD=tuaPassword
playwright install chromium

RAG / ChromaDB errori

pip install chromadb sentence-transformers
# Prima volta: scarica modello embedding (~90MB) — poi funziona offline

Rate limiting (HTTP 429)

ℹ️
Il client gestisce automaticamente con exponential backoff. Con molti patron (>5000) le fetch complete richiedono qualche minuto.
